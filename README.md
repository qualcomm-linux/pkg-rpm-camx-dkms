# pkg-rpm-camx-dkms

RPM packaging for the Qualcomm Linux CamX camera kernel driver on CentOS Stream 10.

This repository packages the upstream [camera-driver](https://github.com/qualcomm-linux/camera-driver) source and uses DKMS to build CamX camera kernel modules on the target system.

The main branch contains repository documentation and workflow support files.
